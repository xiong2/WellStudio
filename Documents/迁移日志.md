# 迁移日志

## xbasic

最基础的包，居然无法将 Warning 级别调至最高，甚至都无法调至 level 2.

## xdata

里面很杂，包含了很多 UI 的东西

理论上讲，上述两个包，都不应该包含 QtGUI 和 QtWidgets，依赖的过多，耦合性强。

另外，xmathmacro.h 和 xglobal.h 是两个毒瘤，前者，完全可以用 C++ 标准的模板来替代；后者，是全局函数大集合，完全可以分化。

## xdataplus

这里面包含了 mkl 和 lapack 的东西，有一些比较恶心的 C style 与 STL 的尴尬结合。警告甚多。

## xbasicui

目前来看，这是一个比较纯粹的包了，依赖的很少，除了上述提到的那两个毒瘤。

## xgeomodel

也算是比较独立的一块，但居然用到了 osg::Vec3Array。

## xgui

文件非常多，属于一个超大模块，不仅依赖 xbasicui 这条单线，还以来了 xdataplus。

## xguiplus

目前文件也很多，不亚于 xgui，依赖于 xgui，以及其全部依赖的。

## xgraphicview

比较干净的一个包，仅依赖于 xgui 中的 xscene class，以及 xdata，和 xbasic，主要是一些毒瘤。

## xlogplot

## xhistogramplot

## xcrossplot

以上三项的内容比较类似，依赖很少

## xsectionwindow

和以上三项类似，但多依赖一个 dataplus

## x3dwindow

不看还不知道，3dwindow 依赖的包几乎是最多的，除了上述几个窗口的依赖以外，它还依赖了 xgeomodel, xalgorithm 等。

## xbasemapwindow

与 x3dwindow 几乎一致，并依赖于 x3dwindow

## xconsole

几乎需要依赖以上一切

## XStudio

依赖于 xconsole，以及其所依赖的一切

## XLicense

依赖于 xbasic
